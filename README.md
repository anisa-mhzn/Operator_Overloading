# Operator_Overloading
This repository contains basic C++ code based on **Operator Overloading** such as (+,-,>,==) as an important concept in Object Oriented Programming. 

## Purpose
This repository is created for learning, understanding, and practicing Operrator Overloading.

### Concepts Covered
- Baisc Operator Overloading(+,-)
- Relational Overloading
- (*,-) Overloading
- Unary Operator Overloading
- Pre/Post Increment 

## How to Run

### Compile<br>
   - g++ Basic_operator_overload.cpp -o Basic_operator_overload
### Run
   - .\Basic_operator_overload
